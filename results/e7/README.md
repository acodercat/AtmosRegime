- 按补充规则既不是"纯挑选"（一条仍比 given 低 30 多点），也不是"纯用不上"（一条比 60 条高 34–39 点）：
  **两种原因各占约一半**——从 60 条里挑不出（或长提示）丢掉约 35 点，拿到对的条目后还有约 35 点用不上。
- 分模板：一条手册就基本修好 7 个（diffuse、displacement_height、finite_line、henry、raindrop、sun_photometer、
  surface_multiple_reflection，16–20/20）；一条也几乎没用 5 个（co2、ch4、clausius_clapeyron、evaporative、line_broadening，0–5/20；
  其中 line_broadening 有措辞歧义）。co2/ch4/CC 一类（题里给参考点斜率，要用对数 / 平方根 / 指数关系外推）8B 拿到公式也套不对。
- 反常：inertia_gravity 60 条 19/20、一条只有 11–13/20；anelastic 一条反而低于 none（5/20 对 9/20、7/20 对 17/20）。

## 教科书陷阱（E7p，none 与手册同批，3 次）

| regime（需识别）陷阱，开思考 | none | 手册 | 差（按陷阱重抽 95% 区间） | 母题正确率 none → 手册 |
|---|--:|--:|--:|---|

- 按规则教科书部分为"修好（≥ +15）"，区间不含 0，母题不降。**60 条手册在教科书 regime 陷阱上对 8B 有效**，
  而在专门难住大模型的模板上只帮一点——可能因为那批模板的替代做法更偏、更难套用（未检验）。
- **伤害**：概念混淆类陷阱 87% → 45%（基座）、87% → 62%（C0），同批测得、可信；正负号类基座 −11 点。手册会让模型把修正套到
  不需要的题上。
- 总判定（PREREG_E7 表）：模板恢复比例 < 20%、教科书 ≥ +15——落在表的空档，如实报告为"教科书修好、模板未修好"。
