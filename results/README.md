Every result number comes from a file here, regenerated from the stored runs under
`experiments/` (gitignored; `docs/IMPORTED_RUNS.md` says where each set came from) — nothing is
transcribed by hand. The training results are regenerated by `atmoscoder_rl/analysis.py` (below);
the pre-registered template experiments by the commands in `prereg/README.md`. The one exception
is the process record in `docs/PROPOSAL.md` appendix B, which no script recomputes.

```bash
# --experiments defaults to this repository's experiments/. On the server that is a symlink
# to $ATMOS_ROOT/experiments, which holds the RL checkpoints' runs (docs/IMPORTED_RUNS.md).
uv run python -m atmoscoder_rl.analysis paper      # base vs every seed's s120
uv run python -m atmoscoder_rl.analysis control    # real reward vs the random-reward arm
uv run python -m atmoscoder_rl.analysis traps      # trap families, parents, shortcut capture
uv run python -m atmoscoder_rl.analysis pairs      # McNemar, trap vs parent, per arm
uv run python -m atmoscoder_rl.analysis frontier   # the same paired test on the API models
uv run python -m atmoscoder_rl.analysis passk --base results/run2/base_pass64.json \
                                              --rl-file results/run2/rl_pass64_s120.json
```

**Arm sizes in these files are as of the date each was written.** The regime arm appears as
43, 47, 59 and 41 in different files because the filters (twins in or out, judgement-measuring
only, magnitude defects excluded) and the corpus both changed between them. The current arm is
whatever `traps.arm_ids` returns — 46 regime, 21 replacement-given, 72 geometry as of
2026-09-14 — and a regenerated file will carry that. **`arm_ids` counts corpus records, and a
record only enters a test once it has runs**: the six Phase-11 traps were in the corpus from
2026-09-13 and measured on 2026-09-14, so between those dates `arm_ids` said 46 while only 41
pairs had data. `analysis pairs` prints the pairs it actually used; trust that number.

Verdicts are **re-derived from each record's `details`** (expected vs actual with units),
not read from the stored `passed`. The cross-domain sets were evaluated before their units
were restored, so their stored verdicts under-credit correct answers given in a
commensurate unit; re-grading moves the base 27.5 -> 29.0 and s120 48.1 -> 50.4, leaving
the effect (+20.6 -> +21.4) unchanged.
