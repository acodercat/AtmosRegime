数据：X 评测的 `textbook.json`（92 行 = 46 道 regime 陷阱 + 46 道父题；陷阱即 `traps.arm_ids("regime")` 中父题不在训练划分里的那些，其中 8 道是
`traps_regime_twins.json` 的孪生记录），每个标签一次运行，判分用运行器的结论（与 `x_report` 的 textbook 块同口径）。
本地只读副本 `experiments/x_textbook/`。单位 = 陷阱；一个臂的逐陷阱正确率是它 4 个终点（两折 × 两种子）的平均；区间按陷阱重抽 10,000 次

不是预注册项（PREREG_X 第 6 节没有教科书陷阱的判定）；2026-10-29 写于看过全部 X 结果之后。

## 3. 读法

1. **正确性奖励让教科书陷阱从几乎全错变成部分能做，随机奖励不能。** Qwen3-8B 五个真实奖励臂都把 46 道陷阱从 2.2 % 提到 15–19 %
   （配对增益 +11 到 +16，区间全在 0 以上；不一致计数 11–16 : 0–2），R 臂 +1.1 [−2.2, 5.4]。Qwen3.5-9B 从 34.8 % 到 48–55 %（A +20.1 [4.3, 35.9]），
   训练后与 deepseek 关思考（52.7 %）相当；R 臂退化后反而下降。
2. **"认出陷阱"这一步也在改善，但 8B 仍低。** 父题做对时陷阱也对的比例：Qwen3-8B 7 % → 20–28 %，Qwen3.5 44 % → 60–63 %。
   父题同时上升（8B +10 到 +17 点），所以陷阱 / 父题之比从 0.07 升到约 0.4（8B）、从 0.59 升到 0.85（9B）；8B 的相对差距仍在。
3. **8B 的增益集中在化学陷阱**（7 道，+39 到 +50 点，五个臂一致），动力学 11 道几乎不动（≤ 11 %）；Qwen3.5 相反，增益在动力学（+43）和热力学（+32）——
   它的化学基座已 57 %。与 `results/traps/paired_test.md`（2026-09）的"化学例外"方向一致，也与图谱里化学模板最易（`results/paper/`）一致；每类 ≤ 11 道，只作描述。
4. **失败的形态向父题方法收敛**：8B 失败行中等于父题方法值的份额从 0.09 升到 0.19–0.23，Qwen3.5 从 0.23 到 0.27–0.42。
   与 DOSE-4 "未学会的机制被统一成标准公式值" 同向；是否是训练池含原题行造成的，由 `PREREG_PAPER_ANALYSES` §5 的留出折检验回答。
5. 热身起点 W_f 本身不改善陷阱（8B 4.3 %，9B 40.2 %）；WA/WD 对 W_f 的增益与 A/D 对基座的相近——热身注入的是模板机制的知识，与教科书陷阱的机制不重合。

## 4. 局限

- 46 道陷阱（含 8 道孪生），两模型比较的半宽约 ±15 点；按类别每格 3–12 道，只报数字。
- 陷阱入选时要求推理模型能做对（PROPOSAL §6），偏向"强模型不掉"；gpt55-reasoning 97.8 % 是这一偏差的体现，不是上限。
- 判分用运行器结论（5 % 容差，benchmark 单位规则），未像 `final.json` 那样重评；一次运行、温度 0.3。
- 这是看过 X 全部结果后的描述性分析，不改 PREREG_X 第 6 节任何判定。
