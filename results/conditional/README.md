# 条件化的模板对比（探索性，不在任何预注册里）

预注册的模板指标是"原题正确率 − 越界正确率"。原题正确率不同的模型放在一起比时会被它牵着走：原题做得少的模型能掉的也少。
这里改为按配对看：**同一对里原题做对了，越界题也做对的比例** P(越界 | 原题对)，给出替代、只提示同理。每个模板至少 5 对原题做对才计入；
模板在簇内等权（X5 每个模板自成一簇），按簇重抽 10,000 次（种子 `cond:20261012`）。
`python -m explore.conditional_report`；`d.json`（D 的 16 个配置 + deepseek 关）、`x5.json`（X5 三个配置）。

- **小模型（8–14B，Qwen3.5-9B 除外）**：会做原题的配对里，越界题只做对 15–23%，给出替代后 60–80%。原题会、越界几乎全掉，这一点比"原题 − 越界"表现得更清楚。
- **大模型**（Qwen3.5-27B、Gemma 31B、deepseek 关）：会做原题时越界题做对约三分之二，给出替代后 95% 以上；**仍有约三分之一的"会做的题"在越界后掉了**，给出替代几乎全补回。
  Gemma 31B 开思考掉得最少（81%）。规模与思考减弱缺陷，没有消除——结论与预注册指标一致，幅度更直观。
- **只提示**比越界高 0–10 点（Qwen3.5、Ministral 约 +7–10），远小于给出替代：条件化之后"缺的是知识"的结论不变。
- Granite 8B → 30B 不改善（17 → 17），与原指标中 30B 差距反而更大一致；它是唯一规模无效的家族。Granite 8B 开思考则由 17 升到 49（计入模板 44 → 66）：原指标差距不变（34 → 35），是因为原题正确率也一起升了。30B 开思考 53，与 8B 开（49）相当，开思考时规模同样无效。
- 局限：只用原题做对的配对，计入的模板随模型变化（41–72 个），小模型的估计建立在它会做的那部分机制上；探索性，不作判定。
