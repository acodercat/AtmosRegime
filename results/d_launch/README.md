## Ministral 3 的请求格式

Ministral 3 没有思考开关，规格设 `no_thinking_switch`：请求的 `extra_body` 不带 `chat_template_kwargs`，其余采样字段不变。
原因：vLLM 对带 `tekken.json` 的模型自动用 Mistral 分词器，该模式拒绝任何带 `chat_template_kwargs` 的请求（`vllm/tokenizers/mistral.py`
`validate_request_params`）；改用 `--tokenizer-mode hf` 时，官方 `tokenizer.json` 解码出未还原的字节标记（`Ġ`、`Ċ`），代码无法运行。
两次尝试都在合成探针阶段失败，没有发出任何正式题，目录原样保留（`d_ministral3_*`）。
