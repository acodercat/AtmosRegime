## 指标

- **识别率**：模板 = 越界对 / 原题对（同一组、同一臂）；教科书 = 陷阱对 / 母题对（同一次重复、同一臂）。
- **恢复比例** = (handbook − none) / (given − none)，在模板越界题（按组合并）上算。
- **伤害**：手册臂相对 none 的原题（inside）正确率、母题正确率、教科书其他五类陷阱识别率的变化。

## 判定（每个模型 × 思考设置分别给出）

| 判定 | 规则 |
|---|---|
| **手册基本修好** | 模板恢复比例 ≥ 50%，且教科书 regime 识别率 handbook ≥ none + 15 点，且原题、母题正确率下降都 ≤ 5 点 |
| **部分修好** | 恢复比例 20–50%，或教科书 regime 提升 5–15 点（伤害条件同上） |
| **没修好** | 恢复比例 < 20% 且教科书 regime 提升 < 5 点 |
| **有害** | 原题或母题正确率下降 > 5 点（无论识别率如何，单独报告） |

- 区间：识别率用 Wilson 95%；手册与 none 的配对差（同一组 / 同一题）用 bootstrap 95% 区间（按模板或按陷阱重抽）。
- 全部报告，不剔除。教科书 regime 识别每格约 50–70 次观测、误差约 ±12 点，"部分修好"的下沿在噪声内，引用时须带区间。
- 附带（描述性）：手册臂答错时，越界错答等于捷径值的比例（没用上手册）与其他错误（用了但用错）。

## 与论文主线的关系

## 第二次补充（2026-10-05，三项检查运行前写定）

复核指出：E7s 中"一条手册 50–58%、60 条 16–19%"的差距，可能是"从 60 条里挑不出"，也可能只是"提示太长"；另外简单检索
可能就能补上挑选这一步。离线结果（`python -m explore.handbook_retrieval`，运行前已知）：BM25 以题面为查询，正确条目在前 1 / 3 /
5 条中的比例，模板 59% / 82% / 94%，教科书 regime 陷阱 65% / 82% / 88%。

**检查 1、2**（`build_e7_checks --templates`，实验号 `e7_checks`，Qwen 基座与 C0，开思考，1 次，全部同批）：臂 none、given、
60 条（原顺序）、只附一条、hbL（其余 59 条在前、正确条目最后）、hbP（59 条无关填充在前、正确条目最后，总长度与 60 条相当）、
BM25 前 1 条、前 3 条。指标：模板越界正确率（按模板合并），配对差的 95% 区间按模板重抽；同时报原题正确率。

| 对比 | 测的是 |
|---|---|
| hbL − 60 条 | 正确条目位置 |
| **hbP − hbL** | **挑选**：长度与位置相同，只差其余 59 条是不是物理条目 |
| 一条 − hbP | 提示长度 |
| BM25 前 3 条 − 一条 | 检索能否补上挑选 |

判定（两个模型分别给出；"成立"指差 ≥ 15 点且区间不含 0）：
- **A 挑选成立、检索补不上**（BM25 前 3 条 < 一条 − 10 点）：按"带手册训练、奖励挑对条目"设计 E4'。
- **B 挑选成立、检索能补上**（BM25 前 3 条 ≥ 一条 − 10 点）：挑选这一步交给检索；训练目标改为"拿到条目后用得上"（一条 → given 的差距），
  检索作为方法的一部分。
- **C 挑选不成立、长度成立**（hbP − hbL < 15 且 一条 − hbP ≥ 15）：问题是长提示，不做挑选训练；考虑只附检索出的少量条目。
- **D 其他组合**：如实报告，与用户商定。两个模型判定不同时，以基座为准、C0 作参考。

**检查 3**（`build_e7_checks --variants`，实验号 `e4b_precision`，Qwen 基座与 C0，开思考，2 次）：E4b 定稿变体及其原陷阱、原母题。
报 regime:recognise 与各家族识别率（陷阱对 | 母题对），95% 区间按陷阱聚类重抽，以及两次之间的差。半宽 ≤ 10 点则 E4b 可作 E4' 的
主要测试集；否则 E4' 需更多重复或更多独立陷阱。
