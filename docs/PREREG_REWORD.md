# 预注册：三个模板的措辞复核（2026-10-04，运行前写定）

## 为什么

E7 中 deepseek 开思考、手册里就有对应条目，line_broadening 越界题仍 20/20 答成 Lorentz 宽度，代码注释写着"Lorentz half-width"。
独立审稿认为原题有歧义：先定义"这个宽度"并说明它与压强成正比，再问"这条线的半宽"，自然读法是问刚定义的那个宽度。
同一审稿认为 drop_ventilation（题面给出静止水滴的生长方程后问 dr/dt）有同类问题，clausius_clapeyron_extrapolation 轻度
（"每升 1 K 增加约 X hPa"可读成常数速率）。若成立，这三个模板上的越界失败测的是"怎么读题"，不是"记不记得替代做法"。

## 设计

- 改写见 `explore/e0_reword.py`（`rw:` 前缀，参数与 E0 确认相同，种子 20261002，每模板 20 组：原题 / 越界 / 给出替代）。
  答案不变，只改题面；改写不点名被省略的过程。
- 模型：deepseek-v4-flash（API，每任务 5 并发）与 Qwen3.6-27B（本地），关、开思考各 1 次。
- 对照：同一模型在原措辞上的 E0 确认结果（`e0_confirm`，同参数）。

## 判定（每个模板、每个模型、每个思考设置）

识别率 = 越界对 / 原题对（同一组）。

| 判定 | 规则 |
|---|---|
| **原题失败源于歧义** | 改写后识别率 ≥ 50%，而原措辞 ≤ 25% |
| **知识缺口，改写确认** | 改写后识别率 ≤ 25% |
| 介于其间 | 25%–50%：如实报告，算部分歧义 |
| 改写本身有问题 | 改写后原题做对 < 15/20（提示过强、反向修正）或给出替代 < 15/20 |

- 一个模板在**开思考**下被判"失败源于歧义"（任一模型），就从"大模型也会掉 / 开思考也会掉"的证据中移出原措辞；
  改写版若在两个模型上都判"知识缺口"，可替换进证据（注明改写与日期）。
- 结果全部报告，不剔除。
