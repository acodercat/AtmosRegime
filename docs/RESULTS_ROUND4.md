## 一句话

1. **学会越界答案的机制，没有一个是把替代公式无条件换上去的**：九种干预（X A 臂两家族、DOSE 两家族、OPD 五臂）共 166 个"学会"的（机制 × 干预）格子里替换型 0 个、中间 1 个；原题正确率同步上升，RL / DOSE 终点到 95–100%，OPD 各臂到 48–87%。
   但模型**更少说**"标准做法不成立"——答案奖励的 RL 把显式判断压低了（越界行判不成立 40% → 19%）。
2. **机制的可达性跨厂商相关**（三家族基座 pass@64 两两 Spearman 0.47–0.78，与 17 个模型的失败图谱 0.69–0.74）；强模型学会的机制是弱模型的**超集**（Qwen3-8B 学会的 37 个全部在 Qwen3.5-9B 学会的 62 个里）；三家族都完全够不着的只剩 3 个。
3. **注入示例在教科书陷阱上没有加码**：Qwen3-8B DOSE RL 比只做 RL 的 A 臂 +2.2 [−2.2, 6.5]、比同样热身的 WA 臂 +3.8 [−2.2, 9.8]；特权蒸馏各臂在教科书上几乎不动（+2 到 +5）。

## 复核要点（写在数字前面）

- **原题行在训练分布内**：X 与 DOSE 的训练题库是训练折每个模板的 inside / outside / given 各 20 行（`_inputs/kc/train_F*.json`），奖励对两种变体一样。
  所以 §15 回答的是"学会越界分支有没有以原题分支为代价、两者是不是一起学会"，不是分布外的泛化；留出折的原题 / 越界不对称仍以 F12 为准。
- **判断的解析率不变**：起点与终点的 judge 行可解析比例 0.98–1.00（Qwen3.5 基座 0.92 → 终点 1.00），H / F 的下降不是格式失败。
- **"学会"的口径**同 P1 / §14：终点越界 ≥ 0.5 且起点 < 0.5；起点 A 臂与 OPD 为基座，DOSE 为同种子热身模型；种子平均、折合并；`plume_mixing_lid` 按 X 排除。
- **锚点核对**：Qwen3-8B A 臂学会 37 = 33（基座越界 < 0.5）+ 4（基座已 ≥ 0.5），与 §13 矩阵一致；DOSE 合并分档 22/22、5/8、4/14 与两家 posthoc 合计一致；
  Qwen H1 差 61.3、Ministral 50.0 与两份报告一致；教科书上基座 2.2、A 16.8 与 `results/traps_rl` 一致；S16-c Qwen 的 AUC 0.95 与 `rigor.json` 一致。

## §15 学会的是什么：条件判断还是公式替换

学会的机制上，原题（inside）正确率起点 → 终点，Δinside 的机制重抽区间，按事先定的边界分类（条件型 Δ ≥ −0.10、替换型 Δ < −0.25、其余中间）：

| 干预 | 学会 | inside 起点 → 终点 | Δinside | 条件 / 中间 / 替换 | 起点 inside < 50% 的 | 终点 inside ≥ 90% 的 | 没学会机制的 Δinside |
|---|---|---|---|---|---|---|---|
| Qwen3-8B A 臂 | 33 | 37 → 95 | +58.0 [46.1, 69.2] | 33 / 0 / 0 | 22 | 31 | +51.0 [37.8, 64.0]（n 36） |
| Qwen3.5-9B A 臂 | 25 | 76 → 100 | +23.8 [14.0, 34.2] | 25 / 0 / 0 | 5 | 25 | +12.8 [7.8, 18.3]（44） |
| Qwen3-8B DOSE | 16 | 49 → 100 | +51.4 [34.2, 68.4] | 16 / 0 / 0 | 9 | 16 | +19.3 [12.5, 27.0]（53） |
| Ministral DOSE | 18 | 44 → 100 | +56.1 [43.6, 67.4] | 18 / 0 / 0 | 12 | 18 | +19.0 [12.1, 27.1]（51） |
| OPD P | 32 | 50 → 70 | +20.3 [12.8, 28.2] | 31 / 1 / 0 | 16 | 14 | +8.6 [4.1, 13.6]（37） |
| OPD Pk2 | 21 | 46 → 87 | +40.7 [27.9, 53.6] | 21 / 0 / 0 | 12 | 14 | +11.9 [3.6, 20.5]（48） |
| OPD Pk3 | 11 | 52 → 81 | +29.5 [16.4, 42.7] | 11 / 0 / 0 | 5 | 7 | +15.5 [9.5, 22.1]（58） |
| OPD S | 4 | 28 → 49 | +21.2 [5.0, 43.8] | 4 / 0 / 0 | 3 | 1 | +9.2 [5.8, 12.8]（65） |
| OPD Pshuf | 6 | 25 → 48 | +22.5 [7.5, 37.5] | 6 / 0 / 0 | 5 | 2 | +8.1 [4.5, 11.8]（63） |

- **写定读法 S15-a 在每种干预下都成立**："学会越界答案没有以原题为代价"。替换型 0 个。
- 一个此前没有被看到的事实：**RL 学会的机制，基座多半连原题都不会**（A 臂 33 个里 22 个起点 inside < 50%）。RL 把整个机制的两个分支一起学会，而不是单独换公式。
  OPD 各臂的原题涨得少（P 终点 70%、Pk2 87%），蒸馏学到的更偏越界分支。
- 没学会的机制原题也涨（A +51、DOSE +19），原题的提高一部分是训练的普遍效应；学会的机制涨得更多，终点几乎全部 ≥ 90%。

**S15-b 顺带学会判断？读法不成立，方向相反。** 学会机制上 Δ(H − F)（H = 越界行判"不成立"的份额，F = 原题行判"不成立"）：

| 干预 | Δ(H − F) 学会 | 没学会 | H 起点 → 终点 | F 起点 → 终点 |
|---|---|---|---|---|
| Qwen3-8B A | −9.5 [−19.5, −0.3] | −7.3 [−14.0, −0.7] | 40 → 19 | 22 → 11 |
| Qwen3.5-9B A | −15.2 [−27.3, −4.2] | −11.2 [−17.9, −4.8] | 42 → 17 | 13 → 3 |
| Qwen3-8B DOSE | −3.2 [−17.8, 10.5] | −1.6 [−7.9, 4.7] | 39 → 28 | 15 → 7 |
| Ministral DOSE | −3.2 [−7.8, 1.7] | −6.1 [−12.8, 0.6] | 27 → 5 | 23 → 4 |
| OPD P / Pk2 | +3.0 [−9.1, 14.5] / +10.1 [0.2, 20.4] | +1.1 / +1.1 | 33 → 35 / 37 → 46 | 19 → 18 / 25 → 24 |

- 答案奖励的 RL（A 臂、DOSE 的 RL 阶段）让模型**更少判"不成立"**，越界行和原题行同降，学会与没学会的机制一样；判断的区分度 H − F 也降。
  特权蒸馏不压低判断（P 持平，Pk2 的学会机制 +10.1，下界刚过 0——单臂单种子，只报数字）。
- 读法：**模型学会了做对，却更少说出"这里不适用"**。X 的 P2 说判断能迁移、解题不迁移；这里是反向：教会解题不会教会判断，答案奖励还会压低它。
  与 F5（判"不成立"后照搬标准公式）合起来：判断与解题是两条分开的通道。

附：留出 64 道（test_id）起点 → 终点，Qwen3-8B 基座 34.4 → A 臂 54.7–64.1、DOSE 热身 31–41 → RL 53–58、OPD 各臂 31–39；Qwen3.5 基座 75.0 → A 84–86；Ministral 热身 34–41 → RL 47–56（基座 45.3）。

## §16 难在机制还是模型：三家族

**S16-a 基座 pass@64 的跨家族一致性**（69 个共同机制，按机制重抽）：

| 对 | Spearman ρ |
|---|---|
| Ministral 3 8B ~ Qwen3-8B | 0.78 [0.64, 0.87] |
| Ministral 3 8B ~ Qwen3.5-9B | 0.53 [0.32, 0.69] |
| Qwen3-8B ~ Qwen3.5-9B | 0.47 [0.25, 0.65] |
| 各家族 ~ D 图谱机制难度（17 个配置的平均越界正确率） | Ministral 0.74 [0.58, 0.85]、Qwen3-8B 0.74 [0.58, 0.84]、Qwen3.5 0.69 [0.54, 0.79] |

- 写定读法（三对下界都 > 0.3）**差一点**（最低下界 0.25）→ 只报数字。可写的句子：机制的可达性排序跨厂商相关，并与 17 个模型的失败图谱一致。
- pass@64 = 0 的机制数：Qwen3-8B 14、Ministral 10、Qwen3.5 5；三家族都为 0 的只有 **ch4_forcing_sqrt、clausius_clapeyron_extrapolation、co2_forcing_log**。
  恰一家为 0：Qwen3-8B 5 个（diffuse_transmission、displacement_height_canopy、freezing_point_depth、plume_ground_reflection、saturated_lapse）、Ministral 2 个（doppler_aliasing、henry_depletion）、Qwen3.5 1 个（sonic_humidity_flux）。
  "完全不可达"的集合随模型缩小，但核心交集跨家族稳定。

**S16-b 两个 Qwen 家族 A 臂学会的机制**（这里"学会" = 两种子均值 ≥ 0.5，不限基座起点，所以 Qwen3-8B 为 37 而不是 F7 / §15 口径的 33）：κ 0.23 [0.09, 0.40]，写定读法（下界 > 0.4）不成立。但 2×2 表本身是更强的陈述：Qwen3-8B 学会 37、Qwen3.5 学会 62，**两者都学会 37、只有 Qwen3-8B 学会 0**——嵌套，不是各学各的。
Qwen3.5 多学会的 25 个在 Qwen3-8B 的基座 pass@64 中位数 0.05（9 个为 0）。两家都不会的 7 个：capillary_rise_gravity、ch4_forcing_sqrt、clausius_clapeyron_extrapolation、drop_ventilation、ice_above_flotation、ice_capacitance_shape、sonic_humidity_flux。

**S16-c DOSE 两家族合并**（44 个有剂量观测）：热身后 p 预测学会的 AUC（观测为对、按机制重抽）Qwen 0.95 [0.84, 1.0]、Ministral 0.92 [0.72, 1.0]、合并 0.92 [0.81, 0.99]
（机制级：Qwen 0.96、合并 0.93；Ministral 机制级全为正例，无法算）；合并分档 p ≥ 0.02 22/22、0.005–0.02 5/8、< 0.005 4/14；按家族分层的"有剂量 − 无剂量" +56.7 [24.7, 81.8]（只报数字，不改两家的 H1 判定）。

## 对论文的写法与证据等级

- **F19（探索级；A 臂两家族 Qwen3-8B / Qwen3.5-9B，DOSE 两家族 Qwen3-8B / Ministral，OPD 单家族）**：RL / 注入 / 蒸馏学会的机制全是条件型，原题分支一起学会（起点多半不会）；答案奖励的 RL 让模型更少判"不成立"。
  第三幕加一句："RL 学会的是整个机制的两个分支，不是换公式；但它学会做对之后，更少说出这里不适用。"
- **F20（探索级·只报数字，三家族）**：可达性排序跨厂商相关 0.47–0.78（写定读法"三对下界 > 0.3"差一点，最低 0.25），与 17 模型图谱 0.69–0.74；强模型学会的是弱模型学会的超集；三家族都够不着的只剩 3 个。§3 统一图景加这组数字，不加"可达性首先是机制的属性"这句判定。
- **F21（探索级，Qwen3-8B 单家族 46 道；Ministral 为第三家族上的方向）**：注入示例在教科书陷阱上不加码（+2.2 [−2.2, 6.5]），OPD 几乎不迁移。第四幕加一句。
- 局限：§15 的原题行在训练分布内（留出折以 F12 为准）；H / F 的下降机制未查（可能是答案奖励下判断句被弱化，也可能是模型"做对了就不说"）；§16-b 的 κ 低是因为 Qwen3.5 几乎全学会（62/69），κ 对边缘分布敏感；§17 只有 46 道、化学 7 道。
