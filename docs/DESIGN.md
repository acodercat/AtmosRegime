# 实验设计（第一阶段，2026-09）：划分、五个臂、以及每个臂回答什么

这份文档只说第一阶段的**设计**——为什么这样切数据、为什么需要这些对照臂；X / DOSE / OPD 的臂在各自的预注册里定义。
第一阶段的数字在 `results/FINAL.md`，全部结果的索引在 `results/README.md`，测量缺陷在 `MEASUREMENT_NOTES.md`，核心命题在 `PROPOSAL.md` §3。

## 1. 划分（2026-09-02 冻结）

436 道核心题按**母题 id** 划分，分层抽样（难度 × 十个子领域），陷阱题的母题排除在训练之外。
冻结之后没有再动，所有结论都以这个划分为条件。

| 划分 | n | 作用 |
|---|--:|---|
| `train` | 190 | 提供 rollout；加每题 5 个数值变体 = **1140 训练行** |
| `test_id` | 64 | 同分布留出 |
| `test_core_only` | 63 | 不支持数值变体的题（结构更复杂） |
| `test_book` | 56 | **两本完整留出的教材**（Andrews、Jacob）——跨教材迁移 |
| `probe_trap` | 67 | 原始陷阱题的母题，作为它们的对照基线 |
| `probe_scaffolding` | 77 | 脚手架消融的配对题 |
| `probe_cross_domain` | 131 | **四个非大气环境领域**：土壤 54、水文 37、环化 21、生态 19 |

**探针**（不在划分里，但同样从不训练）：384 道陷阱题（`traps.json` 335 + twins 31 +
extended 18）、12 道 `unseen_book`（第 14 本教材，连基准构建都没用过它）。

两条规则，违反任何一条结果就不可读：

- **母题和它的变体永远同划分。** 数值变体泄露母题的解法，分开会让"留出"名不副实。
- **每个数字必须报划分。** 436 道混合起来的准确率没有意义——`train` 是模型见过的。
  今天有一个具体教训：SFT 在全部 169 道脚手架记录上是 65.1%，在 77 道
  `probe_scaffolding` 划分上是 35.1%（正好等于基座）。第一个数会让人得出反向结论。

**一次性的最终确认**：`unseen_book` 那 12 道从未参与任何调参决定（学习率、评测点、是否开
overlong 都是看着别的留出集定的），用过一次就烧掉，不能再拿它做决定。它**已经不再是"从未被看过"**：
`results/sft/gold_sft.md` 报告了五个臂在它上面的成绩（2026-09-23 核对）。没有记录显示有哪个决定
是看着它做的，但"没人看过"这一条已经不成立。

## 2. 五个臂

| 臂 | 相对 RL 变了什么 | 回答的问题 |
|---|---|---|
| **RL × 4 run**（run2 + 3 seeds） | — | 效应存在吗、跨种子可复现吗 |
| **随机奖励** | 奖励 → 抛硬币，其余逐字节相同 | 是不是 Qwen 的 spurious-reward 假象 |
| **SFT（黄金 solver）** | 算法 **+** 监督来源 | 监督微调能不能做到同样的事 |
| **RAFT**（模型自己的验证 rollout） | **只有算法** | 关键是策略梯度，还是"监督在模型自己的分布上" |

SFT 和 RAFT 必须同时存在，因为 SFT 单独变了两个因素——算法（模仿 vs 策略梯度）**和**
监督来源（人写的 solver vs 模型自己的输出）。RAFT 去掉第二个差异，所以两者一起才能归因。

训练结果只有 Qwen3-8B：granite 在三个学习率下熵塌缩，Llama-3.1-8B 的可训练题池只有 17.6%（Qwen 42.3%），都训不起来。

## 3. 陷阱探针的分层——这是护城河

护城河不是 RL 算法（纯机制研究打不过专做理论的组），是**按物理含义分层的探针**。

上游的裁定字段把陷阱分成三个臂，缺任何一个论证就不成立：

| 臂 | n | 问什么 |
|---|--:|---|
| **必须自己识别失效** | 46 | 主结论：题面不给替代关系，解题者要自己认出旧关系失效 |
| **题面给了替代关系** | 21 | **内部对照**：同一家族、同样物理、同样构造，只去掉识别这一步 |
| **同方法多一步几何** | 72 | 家族对照：扰动存在但方法不变 |

内部对照是整个设计里最强的一环——它把"模型在某类物理上弱"精确成"缺的是识别失效那一步"。

**只用干净臂**（母题在训练集外）。被污染的那些两个家族都显著，因为那里母题的准确率是训练
产物，分不出物理和曝光。

## 4. 要证明什么

> **RL 教会用方程，教不会判断方程什么时候不能用；而后者在教科书里本来就几乎不出现。**

四个层次，各有独立证据：

1. **效应真实且迁移** — 36/36 全正；未见教材 +24.1、跨领域 +19.3、去脚手架 +22.7
2. **不是假象** — 随机奖励九项全在 ±4；数值变体抗污染；SFT 对照证明不是"任何训练都这样"
3. **失效点被定位** — 46 对 65:11、p<10⁻⁷、四次训练各自显著；两个对照臂都是零效应
4. **机制是分布性的** — 训练集里 regime 题 1.6–3.2%；基座在这类题上 64 次采样平均对 0.2 次

## 5. 训练集的容量上限（2026-09-15 实测）

RAFT 的采样顺带量出了一个之前没有的数：基座对 1140 个训练行各采 8 次，

| | 行数 |
|---|--:|
| **一次都没对** | **544（47.7%）** |
| 至少对一次 | 596（52.3%） |

GRPO 只从"有对有错"的组里取梯度。那 544 行信号为零，而基座总对的那些会被动态采样丢弃，
所以真正产生学习信号的是一个更窄的中间带。这解释了两件早先的观察：训练池约 60 步后信号
枯竭（淘汰样本 203 → 7201），以及 regime 陷阱学不会——训练集里只有 3–6 道 regime 题，
而它们大概率就落在那 544 行里。

**加同类题不会改变这个比例**（它由基座能力决定）。要突破只有两条路：更强的基座，或者
**输入重采样**（每次 rollout 现场生成新数值，把 190 个母题变成无限实例）——后者一天开发、
零 GPU，在 README 的 Open 列表里。

## 6. 对环境科学读者的输出

不是"模型有多好"，是一张**可信度分层图**加一份具名的物理陷阱清单：

| 分层 | 子领域 | 判断题占比 |
|---|---|--:|
| 可托付 | 辐射、大气动力学、大气化学 | 0–2.6% |
| 需复核 | 气溶胶、云物理、热力学 | 15–21% |
| 最需专家 | 水文 | 全语料最高（16–19%） |

清单来自 46 对干净 regime 陷阱的机制字段：跨冰点饱和、地转风→梯度风、平面平行→球面路径、
稳态→含累积项、Kelvin 曲率、活度 vs 浓度、有限库容封顶……每一条都是环境科学家审稿时会抓
的错误，而 RL 之后的模型**更自信地**犯它们。
