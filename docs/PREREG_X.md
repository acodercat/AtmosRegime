## 1. 问题与预测

- **P1（RL 只锐化，不创造）**：某机制经答案奖励的 RL 后越界正确率涨多少，由基座在该机制越界题上的 pass@64 决定；pass@64 = 0 的机制不涨。
- **P2（检查行为迁移，知识不迁移）**：训练"标准做法不成立时标记"，这一行为迁移到未训练的机制簇；解题正确率不迁移。
- **热身 × 奖励**（X2 回溯提出）：pilot 里 D 对 A 的优势主要来自热身注入的知识，不是反事实奖励本身。2×2 把两者分开。

## 6. 判定（运行前写定）

区间：按机制（P1）或按簇（P2、迁移）有放回重抽 10,000 次，`random.Random("x:20261012")`；多种子先在机制 / 簇内平均再重抽。

**P1（无热身臂 A、D、F 的训练折机制；两家族分别判）**

- 判定集合：训练折机制中基座 pass@64 = 0 的机制（记 Z）。要求 |Z| ≥ 8（两折合计），否则 P1 不可判定、只报数字。
- **P1 成立**：Z 中没有机制在任一无热身臂、任一种子上越界正确率 ≥ 50%，且 Spearman(基座 pass@64, 臂的越界正确率) 在三个无热身臂上都 ≥ 0.5、机制重抽区间下界 > 0。
- **P1 不成立**：Z 中 ≥ 2 个机制在某无热身臂上 ≥ 50%，且在同臂另一种子上也 ≥ 50%（家族 2 只有一个种子，按点估计判）——写"答案奖励的 RL 在基座 64 次采样零命中的机制上学会了替代关系"，论文框架按此改写。
- 其余：只报数字，不下 P1 结论。
- 报告：每机制的 pass@1 / @8 / @64、每臂每种子的越界正确率；pass@64 在 (0, 0.1] 的机制另列。

**热身 × 奖励（训练折，描述性，主要看家族 1）**

- 报 A、D、WA、WD 的训练折越界正确率与簇区间；D − A、WD − WA（奖励的贡献）、WA − A、WD − D（热身的贡献）。
- 不设门槛；写定的读法：若 WA 与 WD 都 ≥ 80 而 A、D 都 ≤ 40，写"训练机制上的成功由热身注入解释，奖励设计的贡献在 WD − WA 之内"。

**迁移（留出折，所有臂）**

- 每臂留出折越界正确率 − 起点（A、D、F 对基座；WA、WD 对 W_f），按簇；≥ 15 点且区间下界 > 0 才写"迁移"，否则写数字。
  这同时是"不迁移"在第二家族上的复现。
- 次要：留出折 D − A、WD − WA（T 原来的主比较）照报。

**P2（F 对 A，留出折；两家族分别判）**

- **P2 成立**：留出折 H − F 的 F 臂 − A 臂 ≥ 20 点、簇区间下界 > 0；两臂可解析率 ≥ 0.8；F 臂留出折越界正确率与原题正确率（第 5 节第一条的无判断提示评测）都不低于 A 臂 3 点以上（点估计）。
- **P2 不成立**：F 臂 − A 臂 的 H − F < 10 点且区间含 0。
- 其余只报数字。若 D-3 显示该家族基座已"能检测"（区分度 ≥ 20），改报"F 臂能否把区分度再提高 ≥ 15 点"，门槛同上。
- 报告：训练折与留出折的 H、F、H − F；F 臂的全判 0 率、格式失败率；固定抽样（`random.Random("x:20261012:audit")`，留出折越界行 40 条）核读判断是否可解析。

**安全**：每个终点 `test_id` ≥ 起点 − 3 点；低于则加注"能力代价"。

**不完整**：任一预定运行或评测缺失，该家族该折不作确证性判定，已有结果照报。

## 2026-10-12 修订 X-6：知识探针（写于任何 X6 模型调用之前）

### 1. 问题与边界

X5 显示 Qwen3.5-9B 与 deepseek 在 13 个工程模板上几乎不掉，而在大气模板上掉；两种解释分不开：(a) 工程机制的适用条件与替代关系是常见知识，大气的不是；

### 2. 题与问法

### 4. 分析与读法

- 每个模型、每个模板：K̄、R̄（3 题平均）；越界正确率取该模型在 D（大气）或 X5 中的模板越界正确率（20 题）。
- **主分析**：85 个模板上 K̄ 与越界正确率的 Spearman ρ，按模板有放回重抽 10,000 次（`random.Random("x6:20261012")`）。**"知识预测越界失败"**：ρ ≥ 0.3 且区间下界 > 0，
  在三个模型中至少两个成立。
- **两套模板的差别能否由知识解释**（描述性）：报告两套模板的 K̄ 均值之差；把模板按 K̄ 分为高（≥ 2/3）与低（≤ 1/3）两层，层内比较两套模板的越界正确率。
  若层内两套之差都 < 10 点而总体差 ≥ 20 点，写"两套模板的差别主要由知识解释"；若层内差仍 ≥ 20 点，写"差别不由知识解释，更可能来自模板设计 / 筛查"；其余只报数字。
- 另报 R̄ 与越界正确率的 ρ（"被指出数值后能否识别"对越界失败的预测力），描述性。

### 4. X7："先判断再作答"的推理时对照（不训练）

- 题：D 的大气模板输入（`families_v4/templates.json`）每个模板前 5 道越界题（360 题）加 X5 每个模板前 5 道越界题（65 题），共 425 题。

- 另报第一轮判 no 的比例（不问时的自发检出率之外的"被问时检出率"）与 C 臂相对 D 单轮基线的差（描述性，提示不同，不作判定）。

  本研究此前只在 Bench 题库上对 Qwen3-8B 做过随机奖励对照，X 题库与 Qwen3.5 都没有。
- **设计**：R 臂 = 起点基座、题库同 A 臂（`data-x/<折>-A`）、奖励为每个 rollout 独立的公平硬币，其余与 A 臂逐项相同（x_chain 设置、120 步、24 小时上限、X-13 饱和、
  X-14 存档、X-24 沙箱）。正确与否照常执行评分、只写入日志（`true_score`），不进梯度。两家族 × 两折 × 种子 42，共 4 次；运行名 `x-<家族>-<折>-R-s42`。
  现有 `verl_reward_random.py` 按 Bench 的 JSON 解析 ground truth，X 题库是编码格式（`pilot.decode_truth`），实现时改为同一解码；启动前在 smoke 设置下跑 2 步核对。
- **评测**：同第 1 项的新批次，`explore/x_eval.sh` 设置不变。
- **读法**（每家族分别，按簇重抽 `x:20261012`；留出折与训练折都报）：
  - R − 基座（`-b2`）在留出折原题与越界上都 < 5 点且区间含 0 → 写"随机奖励无可检出效应"；
  - A − R 在留出折原题上 ≥ 10 点且区间下界 > 0 → 写"留出折原题的提高来自正确性奖励，不是随机奖励的效应"；
  - R − 基座 ≥ 10 点且区间下界 > 0 → 写"随机奖励也带来 R − 基座 点"，A 的增益另报扣除 R 后的数；
  - 其余只报数字。训练折另报按机制的 A − R（P1 的零命中机制在 R 上是否也为 0）。

### 3. 超长惩罚的检验（条件性）

种子 43 的 Qwen3.5 F2-F 若再次退化（训练期截断比例最后 20 步均值 ≥ 0.3，或评测 `final` 用满 8,192 token 的行 ≥ 5%），说明不是偶发：
另训一组 F2-F（种子 42、43）开 DAPO 超长惩罚（`OVERLONG=1`，其余不变），报 P2 的各项是否随之改变。不退化则不做，种子 42 的退化照 X-27 报告。
